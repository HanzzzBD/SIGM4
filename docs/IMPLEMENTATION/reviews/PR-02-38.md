`PR-02-38` — Bulk import aset CSV/XLSX + template + laporan per baris

## Yang dikerjakan

Menambahkan impor CSV/XLSX dan P-17 `/aset/impor`: templat, hasil per baris/unit, progres dan berkas koreksi. Maksimal 200 baris diproses sinkron; selebihnya lewat outbox/BullMQ. Replay hash 24 jam hanya milik pengunggah, cursor commit bersama aset/audit, dan NT-55 in-app + push membawa tautan laporan saat pekerjaan asinkron berakhir.

Artefak lokal: `build/pr0238-benchmark-e2e.json`, `apps/api/coverage-ci/coverage-summary.json`. Regresi aset putaran awal: 7 berkas/66 uji lulus. Unit API dijalankan satu worker dengan `--testTimeout=15000` karena lint Clock di Windows melampaui bawaan 5 detik; aturan lint tetap diuji. Typecheck, lint, batas impor, build dan validasi dokumen lulus lokal.

**Uji yang gagal bila logika ini dicabut:** `worker retry dan dua pelaksana bersamaan tidak menggandakan unit setelah rollback cursor`, `500 baris: outbox → BullMQ → worker produksi, tanpa tiruan, selesai ≤60 detik`, dan HTTP denial pada ketiga endpoint.
