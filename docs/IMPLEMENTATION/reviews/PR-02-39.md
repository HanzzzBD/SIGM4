## PR

`PR-02-39` — P-20 dan PDF berita acara mutasi aset
Phase: [phase-02.md](../phases/phase-02.md) · Kompleksitas: `L`

Cabang lokal: `feature/PR-02-39-berita-acara-mutasi`, setelah [pendahulu skema](PR-02-39-schema.md) dan [patch dependency](PR-02-39-dependencies.md). Stack bersumber dari fitur PR-02-38; belum dipublikasikan sebagai PR GitHub.

## Yang dikerjakan

Mutasi 1–50 aset sekarang menyimpan satu snapshot operasi dan menjadwalkan satu berita acara lewat transactional outbox. Worker membuat PDF 1.7 A4 dari snapshot setelah transaksi berhasil; perubahan nama master berikutnya tidak mengubah isi dokumen. PDF gagal tidak membatalkan mutasi yang sudah tersimpan.

P-20 `/aset/mutasi` menyediakan pemilihan aset lintas halaman, tujuan aktif, tanggal/alasan dan penanggung jawab opsional. Setelah berhasil, `/aset/mutasi?document={id}` menampilkan status dan unduh PDF. URL privat berlaku 15 menit, setiap penerbitannya diaudit. Permission baru `asset_movement_document.view` mempunyai akses bawaan hanya Admin/Petugas/Pimpinan; akses dokumen aset M-06 tetap memakai permission sebelumnya.

## Catatan untuk peninjau

Cakupan L dipilih produk: P-20 belum tersedia, sehingga form/status/unduh dan pipeline PDF memakai satu kontrak acceptance dari mutasi sampai dokumen. Migration dan patch dependency dipisah sesuai keputusan. Snapshot, object_key dan created_by dilindungi trigger immutable; jobId dan kunci objek stabil, lock sesi worker tidak mempertahankan transaksi DB selama render/upload.

Gerbang audit kini menjalankan endpoint impor PR-02-38 dan membersihkan operasi/registri dengan urutan FK. Fixture impor membersihkan master/counter/penggunanya; benchmark memeriksa event job sendiri sesudah drain yang dapat memproses agregat lain. Fixture pengukuran 100.000 activity log memakai awal bulan UTC yang sama dengan filter uji agar timezone PostgreSQL tidak mengurangi jumlah baris. Tidak ada perubahan logika bisnis lain dari perbaikan harness ini.

PDF keluaran renderer terpercaya diregistrasi CLEAN melalui permukaan M-06 khusus SYSTEM: seluruh teks di-escape, JavaScript/jaringan renderer diblokir. HTTP presign tetap menolak jenis ASSET_MOVEMENT_DOCUMENT; unggahan pengguna tetap mengikuti pemindaian AV yang ada. Registrasi berkas/status SIAP/audit commit bersama; kegagalan finalisasi menghapus objek dan retry, terakhir GAGAL dengan pesan aman.

Tidak ada backfill berita acara lama, nomor surat/signature baru atau tombol retry bisnis. GAP-02-MOVE-SLOT (cek booking pada tanggal mutasi) tetap task terpisah. P-15/P-18 belum tersedia; P-20 dapat dibuka langsung atau dari URL hasil mutasi. QA staging, CI GitHub, merge dan tinjauan arsitek masih pending.
