# PR-01-21 + PR-01-23 — verifikasi lokal 11 Oktober 2026

Pengguna mengizinkan dependensi ekspor PR-01-22 agar PR-01-23 lengkap. Kontrak ditetapkan pada PRD M-03 §7 sebelum implementasi. Belum ada PR remote atau merge yang dilakukan oleh pekerjaan ini.

- PR-01-21: satu agregasi aset per ruangan (`dihapuskan=false`), rollup area/gedung, nol dipertahankan, lokasi nonaktif tetap dihitung. `q` digabung filter kategori/kondisi/status dan ID ruangan; ringkasan tidak terpotong filter. Endpoint aset ruangan tetap memakai `asset.view`.
- PR-01-22: ekspor seluruh hasil tersaring tanpa paginasi; XLSX menulis isian sebagai string, PDF meng-escape HTML. Identitas lokasi, tanggal cetak WIB, nama/ID pencetak disertakan. `report.export` wajib — satu-satunya permission endpoint (`PM-01`); syarat tambahan `location.view` di router dan service dicabut 12 Oktober 2026 karena membuat endpoint ber-dua-permission dan menggagalkan matriks `SEC-T-01` gerbang Phase 01. Audit `DATA_EXPORTED` harus berhasil sebelum berkas dikembalikan.
- PR-01-23: `/lokasi` dan `/lokasi/ruangan/$id`, pencarian/filter/tab/paginasi pada URL, expand/collapse native yang bisa diakses keyboard, formulir gedung/area/ruangan dan perubahan status dengan konfirmasi. Aksi mutasi/ekspor mengikuti permission. Empty state menautkan tambah aset dengan ruangan terpilih. Tab Jadwal Tetap menggunakan `RoomBlocksPanel` dan tidak mengambil daftar ketersediaan ketika konteks ruangannya sudah tetap.

## Bukti dan batas

- Typecheck, build web, lint berkas terkait, dan gerbang batas impor lulus.
- Uji aplikasi lokasi: pohon baca-saja, kombinasi filter URL, penolakan route/server, mutasi gagal dengan pesan, ekspor tersaring; axe WCAG 2.1 AA tanpa pelanggaran (kontras warna tidak dinilai oleh helper JSDOM).
- Uji backend: rollup lintas cabang/nol/nonaktif, validasi `q`, penolakan ekspor tanpa izin, isi XLSX 500 baris/metadata/tipe sel teks, escaping PDF, dan kegagalan audit.
- Uji repository menjalankan query builder PostgreSQL dengan driver rekaman: `location.view` tanpa `asset.view` tetap dapat membaca hitungan; scope restricted, semua filter AND, parameter SQL, pengecualian aset dihapuskan dan ekspor tanpa LIMIT terbukti. Matriks otorisasi `SEC-T-01`, OpenAPI dan registri HTTP mencakup dua endpoint baru.
- Browser Chromium dengan respons API tiruan: pohon terbuka dan detail pada 320/768/1024/1440px, dialog pada 320px; tanpa overflow dokumen. Topbar diperbaiki untuk 320px: jam tetap berlabel WIB, waktu lengkap muncul mulai breakpoint `sm`, nama pengguna dapat terpotong secara visual.
- Suite web awal: 320/323 lulus, tiga timeout pada file lama saat worker bersamaan. Ketiga file (`alur-masuk`, `asset-movement`, `room-blocks`) lulus ulang dengan `--maxWorkers=2` (46/46). File lokasi, formulir aset dan alur shell juga lulus (40/40 setelah tambahan uji lokasi).
- `apps/api/tests/integration/m04-assets-list.test.ts` menambahkan acceptance PostgreSQL 500 unit ≤ 2 detik, isolasi ruangan, kombinasi filter, aset dihapuskan dan hitungan pohon. **Dijalankan 12 Oktober 2026** pada basis data uji PostgreSQL lokal sekali pakai: lulus (asersi ≤ 2 detik terpenuhi). Ini bukti lokal, bukan staging — closure staging tetap terbuka.
- PDF diuji melalui renderer tiruan untuk isi HTML; render Chromium terhadap PostgreSQL/staging masih perlu diverifikasi.
