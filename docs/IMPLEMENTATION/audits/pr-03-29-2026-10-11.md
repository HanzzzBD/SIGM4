# PR-03-29 — UI dokumen aset

Implementasi lokal 11 Oktober 2026; belum ada PR remote/merge. Pengguna memilih pencarian nama/kode untuk aset tambahan dan menyetujui penambahan API yang diperlukan agar P-26 lengkap.

## Perubahan

- P-26 `/dokumen-aset`: daftar lintas aset, pencarian nama berkas/kode/nama aset, jenis, kategori, masa garansi, urutan dan paginasi pada URL. Deep link UX `filter[garansi_berakhir_hari]=30` diterjemahkan ke filter kanonis, dan dihapus saat reset saringan. Satu baris per tautan dokumen-aset aktif; dokumen yang sama dapat muncul pada beberapa aset.
- P-18 `/aset/{id}/dokumen`: tab Dokumen hanya bagi `asset_document.view`, dengan gerbang route bersama `asset.view`. Tab dan kontennya dimuat malas, respons daftar memakai skema bersama API/web.
- Unggah PDF/JPG/PNG/DOCX/XLSX maksimal 10 MiB, validasi MIME/ekstensi/ukuran/keterangan/garansi, pencarian dan pilihan aset tambahan. Presign → PUT tanpa cookie/header sesi ke object storage → confirm checksum SHA-256 → tautkan satu dokumen ke beberapa unit. Bila penautan gagal setelah confirm, percobaan ulang dalam formulir yang sama memakai file_id tersebut. Status proses dan galat tampil, isian tetap tersedia setelah gagal.
- Berkas PENDING diperiksa ulang tiap 5 detik ketika halaman aktif. PENDING/INFECTED/FAILED tidak dapat diunduh, dengan alasan tertulis. CLEAN meminta URL bertanda tangan saat klik; signed URL/object key tidak disimpan dalam daftar. TTL 15 menit dan audit unduhan tetap dimiliki endpoint backend yang sudah ada.
- Lepas tautan dengan dialog yang menjelaskan dampak tautan terakhir; gagal tetap di dialog, berhasil memperbarui daftar dan linimasa aset. Fokus modal terkunci dan kembali ke pemicu setelah batal, atau wadah daftar bila pemicu sudah hilang.
- Penanda masa garansi aktif/belum dimulai/berakhir dalam ≤30 hari/berakhir berdasarkan tanggal WIB. Tidak menambahkan job notifikasi garansi (milik PR-03-26).
- UX P-26/tab Dokumen diperbaiki dari `asset_movement_document.view` ke permission kanonis M-06 `asset_document.view`. Permission dokumen mutasi tetap terpisah.

## API dan batas data

Kontrak ditetapkan di PRD M-06 §7: `GET /asset-documents`, `asset_document.view`, query filter/paginasi tervalidasi dan terdaftar di OpenAPI. Registri HTTP, OpenAPI dan matriks otorisasi berasal dari definisi route yang sama. Generator menerima skema query opsional agar filter API baru ikut terdokumentasi.

Scope dokumen diterapkan pada daftar lintas aset, daftar per aset, hitungan tautan terlihat, unduh/lepas, dan sumber garansi M-11: all seluruhnya, own pengunggah sendiri, assigned aset yang menjadi tanggung jawab pemanggil, restricted tidak mendapat dokumen. Siswa/OSIS tidak mendapat dokumen. Scope assigned juga membatasi aset tambahan sebelum penautan. Dokumen dihapus/tautan tidak aktif dikecualikan; aset dihapuskan tetap boleh mempunyai dokumen (BR-008). Tidak ada migration.

UI mengendalikan aksi berdasarkan permission; backend memeriksa scope tiap permintaan. P-26 tetap bisa dibaca pemegang `asset_document.view` tanpa `asset.view`; tidak mengambil kategori atau menampilkan tautan detail/unggah pencarian aset dalam kasus tersebut.
