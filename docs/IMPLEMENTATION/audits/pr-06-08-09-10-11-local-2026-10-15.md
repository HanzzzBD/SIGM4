Fresh actor dibaca dari SQL, bukan snapshot JWT atau izin yang dikirim ke worker.
Job privat pemohon: Administrator lain juga mendapat 404. Hash izin mencakup
role_version dan seluruh grant/scope; hash keanggotaan memeriksa perubahan pemilik
atau penugasan. Data dan ringkasan memakai predicate penyedia yang sama.
Operasional tidak meminta report.view tambahan. Scope yang belum didefinisikan
ditolak. Finansial tetap mengikuti kontrak provider sumber.

Worker memakai advisory lock per job. Rendering/upload berjalan di luar transaksi
data; publikasi file, status, log dan event dalam satu transaksi. UPDATE selesai
mensyaratkan status BERJALAN agar pembatalan selama render tidak dipulihkan.
PUT yang responsnya hilang tetap dikompensasi dengan penghapusan; retry tidak
menggandakan file/log/notifikasi. Cleanup mempertahankan kandidat gagal hapus
untuk percobaan berikutnya, melepas relasi metadata melalui M-06 setelah hapus.
Owner REPORT_EXPORT hanya dapat dibuat generator tepercaya, bukan presign klien.

Migration **0070_report_exports.sql** menambah tabel, enum owner dan tiga parameter
identitas kosong dengan ON CONFLICT DO NOTHING. Down menghapus tabel; nilai enum
dan identitas sekolah dipertahankan. **0071_analytics_asset_owner_index.sql**
menambah indeks assets(penanggung_jawab_id,id). Migration hanya dijalankan pada
database uji sementara, belum pada database aplikasi.

UI membedakan nilai uang dari hitungan dan label, menggunakan string desimal
untuk tampilan/selisih. Grafik maksimal 20 baris halaman aktif; konsumsi bahan
memilih satu satuan agar rim dan pcs tidak dicampur. Nilai terlalu besar untuk
geometri numerik aman tetap tersedia sebagai teks/tabel. Region tabel dapat
difokuskan dan digulir dengan keyboard. Cache query dipisah menurut akun, role
dan grant/scope; panel job direset saat identitas berubah. Pengiriman yang belum
pasti mempertahankan payload dan idempotency key untuk percobaan ulang identik.

## Pengujian

**94 uji unik backend/web dan 20 kasus browser lulus.** Hitungan ini tidak
menambahkan ulang tes yang dijalankan beberapa kali.

- **29 integrasi PostgreSQL**: 11 ekspor, 7 fondasi dan 11 provider produksi.
  Suite gabungan 27 lulus sebelum penambahan dua kasus ekspor; suite ekspor final
  11/11 lulus sesudah penambahan race pembatalan dan konfigurasi kop.
  Memakai PostgreSQL 18 lokal terisolasi; launcher ekspor port 55448 memakai
  database acak dan membersihkan cluster setelah proses.
- Ekspor menguji file XLSX nyata dan PDF Chromium/PDF 1.7, DECIMAL dan teks
  mirip formula, scope/privasi lintas akun, perubahan grant/pemilik, batas PDF,
  lima tahun vs tampilan 366 hari, idempotensi HTTP lintas akun/endpoint,
  SLA dan filter operasional, semua opsi filter, penugasan teknisi, NT-42,
  kegagalan PUT/hapus, expiry, race pembatalan, serta PDF tanpa nama sekolah
  ditolak sementara XLSX tetap tersedia. HTTP request tidak merender file.
- **40 unit/kontrak backend**: M-16, health/OpenAPI, enum dan Clock.
- **25 web**: 12 analitik/ekspor dan 13 label/navigasi. Memeriksa URL/filter,
  pembanding/selisih, grafik/tabel/aksesibilitas, kondisi kosong/error, retry
  idempoten, deeplink privat, izin baca tanpa ekspor, kedua panel operasional,
  representasi finansial dan pergantian akun dalam QueryClient yang sama.
- **20 browser**: lima halaman pada 320/768/1024/1440 px. Axe WCAG A/AA termasuk
  kontras: nol pelanggaran; nol galat JavaScript/overflow horizontal halaman.
  Keyboard, tabel focusable, pemisahan satuan grafik dan POST ekspor tanpa
  pagination diverifikasi. Menggunakan production build dengan API fixture.

Typecheck produksi workspace serta tests API/web, lint perubahan dan 14 pemeriksaan
batas impor lulus. Production build web lulus; peringatan chunk utama sekitar
501 kB serta campuran import NotificationCenter tetap tercatat sebagai batas
build saat ini. Indeks dokumen, audit dokumen dan validate_impl dijalankan sesudah
pembaruan catatan.

Runner browser: scripts/qa/analytics-browser.mjs. Artefak lokal tmp/pr0608-browser.json,
tmp/pr0608-*.png dan tmp/pr0608-ui-tests.json. Perbaikan saat verifikasi meliputi
transform SLA satu kali pada batas baca, coercion boolean/ID URL TanStack,
containing block teks pembaca layar tabel, dan lebar input pencarian P-30/P-39
pada layar 320 px. Semua kasus terkait telah diulang dan lulus.

## Bukti performa PR-06-09

Runner scripts/qa/analytics-performance.mjs menolak database nonlokal/nonsementara.
Dataset: **105.001 aset dan riwayat kondisi**, 5.000 aset target, serta masing-masing
5.000 pinjaman, kerusakan, WO dan penyerahan bahan. Semua delapan jenis memiliki
EXPLAIN ANALYZE/BUFFERS untuk rows, summary dan statement gabungan yang dipakai
HTTP. Lima sampel per jenis memanggil AnalyticsService.report nyata. Nilai berikut
adalah p95 empiris lokal dari lima sampel (nilai terbesar), bukan pengukuran HTTP
ujung ke ujung atau uji beban bersamaan.

mengubah aturan sumber. Rekonsiliasi provider produksi ikut menguji optimasi.
