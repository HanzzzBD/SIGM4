# Audit implementasi PR-01-22 + PR-02-47

Tanggal: 12 Oktober 2026. Perubahan lokal; belum dibuat commit atau PR.

PR-01-22 sudah digabung melalui #169 (`c2ed39c`). Implementasi ini memperkuat ekspor lokasi yang sudah tersedia dan melengkapi PR-02-47.

## Perilaku

- `GET /assets/export?format=xlsx|pdf` dan tombol ekspor P-15 mengekspor seluruh hasil pencarian, filter, dan urutan katalog, tanpa pembatasan halaman. Parameter ekspor menggunakan pembangun filter yang sama dengan daftar inventaris. Parameter tidak dikenal dan paginasi ditolak.
- Endpoint memakai satu permission `report.export`, sesuai PM-01. Scope `all`, `own`, `assigned`, dan `restricted` diiriskan dengan `asset.view` bila dimiliki. Akun khusus yang hanya memiliki permission ekspor tetap menggunakan scope ekspornya. Aset terhapus dikecualikan. Filter pekerjaan impor memeriksa kepemilikan pengunggah.
- Kolom finansial tidak dipilih SQL atau disertakan dalam berkas tanpa akses. Scope finansial `own`/`assigned` meredaksi nilai di luar scope per baris. Siswa R-07 dan scope terbatas tidak memperoleh kolom finansial. Nilai decimal dipertahankan sebagai teks agar tidak kehilangan presisi Excel/JavaScript; teks seperti nomor seri dan awalan formula tetap teks.
- Berkas membawa identitas, tanggal WIB, pencetak, filter, dan jumlah hasil. PDF meloloskan teks masukan melalui escape HTML. XLSX membekukan kepala tabel dan menyediakan auto-filter.
- Kedua ekspor mencatat `DATA_EXPORTED` sebelum mengirim berkas. Logger audit dapat mengembalikan `false` tanpa melempar galat; kedua layanan kini menolak hasil tersebut. Respons memakai attachment dan `Cache-Control: no-store`.
- Ringkasan ruangan mengikuti scope katalog `own`/`assigned` agar hitungan sesuai akses pemanggil. Penguatan scope juga diterapkan pada ekspor lokasi.
- UI menyembunyikan tombol tanpa permission, mencegah unduhan rangkap selama proses, dan menampilkan galat saat server menolak ekspor.

## Verifikasi

- Seluruh suite unit API: **1.289 pengujian lulus**, 84 berkas. Termasuk kontrak OpenAPI, permission, rate-limit registry, scope SQL, finansial, audit gagal, serta XLSX 5.000 baris tanpa paginasi.
- Seluruh suite web: **381 pengujian lulus**, 30 berkas. Pengujian terpilih sebelumnya: **22 lulus**, termasuk dua format, filter boolean `false`, unduhan tanpa page/per_page, tombol permission, penolakan 403, dan aksesibilitas axe.
- Typecheck, build produksi web, lint workspace, lint root dengan pengecualian `.kilo/**`, pemeriksaan batas impor, dan `git diff --check` lulus. Build melaporkan peringatan import statis/dinamis modul notifikasi yang sudah ada.
- Smoke test renderer Chrome nyata untuk tabel 50 baris menghasilkan PDF 36.595 byte dengan header `%PDF-1.7`. Pemeriksaan template ekspor dilakukan dalam pengujian layanan; smoke test ini memeriksa renderer bersama, bukan database produksi.
- Acceptance PostgreSQL ditambah untuk ekspor 26 hasil tersaring tanpa aset terhapus dan redaksi finansial restricted. **15 pengujian integrasi katalog dilewati** karena `DATABASE_URL` tidak tersedia. Verifikasi data PostgreSQL dan staging masih terbuka.

Perubahan akun PR-02-40/41/42 yang sudah ada di workspace dipertahankan.
