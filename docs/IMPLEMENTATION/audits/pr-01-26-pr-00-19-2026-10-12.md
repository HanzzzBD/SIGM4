# Audit implementasi PR-01-26 + PR-00-19

Tanggal: 12 Oktober 2026. Perubahan lokal, belum commit/PR. Perubahan akun, ekspor, mutasi dan CSV dari tugas sebelumnya dipertahankan.

## PR-01-26 — PM-05 melalui JWT/sesi hidup

`tests/integration/permission-live-session.test.ts` merakit aplikasi produksi dengan JwtKeys Ed25519, PermissionCache Redis, SessionStore PostgreSQL, penyimpan challenge Redis dan RedisRateLimiter. Login Administrator melewati password dan verifikasi TOTP melalui HTTP; pengguna uji login melalui bearer Android atau cookie web. Tidak ada authPalsu, SessionChecker tiruan, penyisipan AuthContext, atau JWT yang diterbitkan langsung untuk melewati login.

Perubahan matriks dilakukan melalui PUT /roles/{id}/permissions, dan pergantian role melalui PUT /users/{id}, memakai sesi Administrator tersebut. Token pemanggil tetap sama dan Clock tidak dimajukan; cache versi lama masih ada dengan TTL positif ketika permintaan berikutnya memakai izin baru. Lima acceptance membuktikan prasyarat, pencabutan/pemulihan izin pada bearer dan cookie, perubahan scope ALL menjadi RESTRICTED (dua aset menjadi satu aset yang boleh dipinjam siswa), serta pergantian dua role dengan role_version sama yang langsung mencabut lalu memulihkan akses.

Pembuktian dijalankan pada instance PostgreSQL 18.3 dan Redis 5.0.14 terpisah di loopback, dengan cluster/database kosong khusus QA. Semua 51 migration diterapkan, tanpa memakai database aplikasi pengguna. Fixture dibuat dengan penanda unik dan dibersihkan menurut ID akun/role; tanpa FLUSHDB. Instance sementara dihentikan setelah verifikasi. Logika runtime PM-05 yang sudah tersedia lulus tanpa memerlukan perubahan autentikasi tambahan.

## PR-00-19 — publikasi OpenAPI

GET /api/docs menyajikan JSON OpenAPI yang dibuat dari registri pada bootstrap aplikasi, tanpa amplop bisnis atau salinan kontrak manual. Publikasi diaktifkan hanya melalui APP_ENV=development|staging; production atau konfigurasi yang tidak diberikan menutup route dengan 404. NODE_ENV tidak mengaktifkannya. Route dokumentasi berada di luar /api/v1, berdeklarasi publik, dikenai rate limit dan header keamanan serta no-store/noindex.

APP_REVISION mengisi info.version. CI membangkitkan JSON dari dist hasil checkout/build yang sama dan menerbitkan artefak openapi-${GITHUB_SHA} dengan retensi 90 hari. Push tag v* ikut pipeline; artefak tag membawa versi tag, sedangkan image runtime membawa SHA dari build arg. Compose staging memasang APP_ENV=staging dan proxy /api/ yang sudah tersedia meneruskan dokumentasi. Smoke staging memeriksa bentuk OpenAPI dan SHA terhadap SMOKE_EXPECTED_REVISION dari commit deploy.

URL development, pola URL staging sesuai vars.STAGING_DOMAIN, konfigurasi, pemeriksaan commit dan rollback dicatat di [runbook](../runbooks/openapi.md). Domain/VPS/environment staging nyata belum tersedia dalam workspace; tidak dilakukan deploy atau publikasi eksternal. Bukti ini menutup implementasi kode, bukan QA deployment staging.
