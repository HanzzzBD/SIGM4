## Keputusan pengguna

Enam jawaban AskUserQuestion dicatat pada [M-19 §7](../../PRD/02-modules/m19-chatbot.md):

- Jempol turun hanya penilaian. Laporkan masalah meminta izin berbagi seluruh
  sesi kepada Admin; hanya R-01 membuka isi laporan. Pimpinan melihat agregat.
- HTTP 429 penyedia langsung menampilkan gangguan dan waktu coba lagi;
  koneksi/5xx maksimal dua retry, tanpa mengulang output yang sudah streaming.
- CHAT_ENABLED=false boleh tanpa key; true memerlukan GEMINI_API_KEY saat startup.
- Kuota awal 50 pesan/akun/hari untuk seluruh role, reset 00.00 WIB, diatur M-20.
- Hapus sesi atau retensi 90 hari menghapus isi/steps dan relasi akun permanen;
  agregat statistik anonim tetap disimpan.
- Pertanyaan tersering memakai kategori tool/pola seperti Lokasi aset atau
  Stok bahan; tidak membuka teks pertanyaan pribadi.

## Implementasi dan batas integrasi

Migration expand **0069_chatbot.sql** menambah sessions/messages,
usage_daily, evaluations dan restrictions serta empat parameter M-20.
Up/down/up diuji sebelum fixture diisi. Down menolak setelah ada data;
gunakan forward fix setelah modul dipakai. Migration 0067/0068 sesi M-22
dipertahankan, fixture M-19 dipin sampai 0069.

SDK resmi **@google/genai 2.29.1** hanya di adapter ChatProvider. Pemanggilan
Interactions memakai store:false, seluruh steps/signature pada request
stateless, thinking minimal, batas keluaran 1.000 token dan tools kustom.
Daftar 12 deklarasi diurutkan tetap termasuk ketika tool_choice:none.
Token dihitung melalui API model, dengan pruning giliran utuh pada anggaran
16.000. SDK retry otomatis dinonaktifkan; aplikasi mengendalikan retry.
Tidak ada AFC, previous_interaction_id, built-in search maupun endpoint tulis AI.
Referensi kontrak SDK: [Interactions](https://ai.google.dev/api/interactions-api)
dan [SDK JavaScript](https://googleapis.github.io/js-genai/release_docs/index.html).

Repository domain privat diakses melalui index.ts pemilik. SQL memaksakan
permission/scope/pemilik, memakai parameter dan transaksi READ ONLY dengan
statement_timeout 5 detik. Projection/allow-list membuang identitas, nilai
finansial dan path storage. Schema strict menolak user_id buatan model.
Siswa tidak menerima aset/ruangan yang tidak diizinkan. Ketersediaan mengikuti
horizon M-20, kondisi/status dan klaim penghapusan yang dipakai reservasi. Tool pribadi tetap
milik penanya meskipun Admin memiliki scope all. Tool Bahan memuat saldo
agregat/lokasi/satuan/ambang, tanpa transaksi atau identitas peminta.

Sebelas endpoint berpermission/OpenAPI memakai UUID pesan, hash payload dan
satu giliran PROCESSING per sesi. Replay tidak mengonsumsi kuota lagi.
Idempotency mutasi diikat ke pelaku/endpoint. Perubahan permission memutus
history model dari scope lama. Redis kuota harian atomik gagal tertutup.
Pengalih instalasi dan M-20, health LLM nonkritis, batas lima eksekusi tool,
timeout serta respons netral menjaga modul lain tetap berjalan.

Web dan mobile menyediakan riwayat berhalaman, streaming, kuota/token akun,
feedback, laporan berizin dan konfirmasi hapus permanen. Teks model dirender
sebagai teks; hanya referensi server menjadi tautan. Panel web dimuat lazy
dan memakai dialog dengan fokus/Escape. Mobile memakai client autentikasi
bersama dan Expo fetch, tanpa cache/SQLite/antrean percakapan; stream dibatalkan
saat akun berubah, unmount atau aplikasi masuk background. Detail native
berizin digunakan jika tersedia, sisanya origin HTTPS aplikasi tepercaya.

Worker SYSTEM harian 01.50 WIB menghapus sesi berusia 90 hari sejak awal sesi,
menutup orphan PROCESSING dan mempertahankan agregat tanpa ID/teks.
Salinan respons pribadi di idempotency_keys ikut dihapus. Audit tindakan
menyimpan metadata sesuai AL-09, tanpa salinan isi/steps.
