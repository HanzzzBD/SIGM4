# Audit lokal PR-05-24 — 14 Oktober 2026

Implementasi lokal FR-13.4/BR-093/094/095 mencakup sesi Bahan pada M-13,
penyesuaian ledger M-22 sesudah persetujuan Pimpinan, PDF/XLSX privat,
web P-48/49/50 dan mobile MS-22/23. Status **In Progress** sampai tinjauan
arsitek, CI remote dan staging. Tidak membuat commit/PR remote, merge,
deployment atau menerapkan migration ke database aplikasi.

## Keputusan pengguna

Tiga jawaban AskUserQuestion telah dicatat pada PRD M-13 §6 dan kontrak §7:

- Perubahan transaksi sesudah hitungan menghalangi persetujuan; hitung ulang
  dengan saldo terbaru. Snapshot awal tetap menjadi riwayat.
- Pengecualian luring Aset diperluas ke hitungan Bahan: cache terverifikasi
  72 jam per akun/sesi/lokasi, persistensi hasil, sinkronisasi daring;
  penyelesaian lokasi, finalisasi, pengiriman dan persetujuan wajib daring.
- Target mencakup pasangan saldo yang tercatat untuk bahan aktif, bahan aktif
  pada lokasi bawaan meski belum memiliki saldo, dan bahan nonaktif bersaldo positif.

Aturan target dan izin luring bukan hasil asumsi implementasi. SDD-05/12 dan
UX PAGE-SPECIFICATION telah diselaraskan; indeks PRD/traceability diregenerasi.

## Perubahan dan integrasi

Migration expand **0066_material_stocktake.sql** menambah audit_material_items
dan memperluas domain sesi yang sudah ada. Snapshot identitas/satuan/lokasi/saldo
tidak dapat diubah atau dihapus. Trigger mencegah pencampuran domain dan perubahan
hitungan sesi tertutup. Migration 0067/0068 serta transaksi bisnis M-22 milik sesi
lain dipertahankan; fixture M-13 dipin sampai 0066 agar sumber uji stabil.

Lima endpoint khusus Bahan memakai kontrak bersama dan permission audit.execute,
audit.view atau audit.manage. Endpoint target Aset menolak domain Bahan. Hitungan
memakai UUID, revision, saldo dan ID ledger terakhir per bahan/lokasi. Perubahan
stok dengan jumlah akhir sama tetap terdeteksi. Hitungan belum diisi tidak berubah
menjadi nol. Keterangan wajib untuk delta efektif; selisih snapshot tetap tersedia.

Persetujuan memerlukan Pimpinan R-03/audit.approve dan melarang pembuat/pelaksana
menyetujui sesi sendiri. Semua material dikunci berurutan, basis diperiksa ulang,
dan delta nonnol dicatat melalui MaterialLedgerService. Audit, ledger, agregat,
penutupan sesi, snapshot laporan serta outbox satu transaksi. Penolakan membuka
kembali hitungan tanpa mengubah stok. Dua persetujuan serentak tidak menggandakan
penyesuaian. NT-30 memakai jumlah pasangan bahan/lokasi; NT-31/32 dan worker
laporan memakai mekanisme sesi yang sudah ada.

Web menyediakan pilihan domain pada form, detail/progres Bahan, keterangan,
pengiriman, keputusan Pimpinan, pembatalan Admin dan laporan. Jalur API Aset
tidak dipanggil halaman Bahan. Retry setelah hasil write belum pasti memakai
body/key sama. Mobile memuat seluruh halaman target per lokasi, memisahkan cache
Bahan/Aset, memakai QR privat /b/ atau pemilihan baris, dan menyimpan jumlah
secara atomik sebelum menampilkan berhasil. Cache kedaluwarsa mempertahankan
antrean yang belum tersinkron; logout membersihkan akun. Galat permanen tampil
untuk tindakan pengguna, tanpa menghapus hitungan secara diam-diam.

Skala produksi **L** dipertahankan sesuai rencana phase: satu perubahan domain
memerlukan migration, kontrak, gerbang persetujuan dan kedua klien yang kompatibel.
Pemecahan bagian tersebut akan meninggalkan alur opname Bahan yang belum dapat
digunakan. Tidak mencakup penerimaan/permintaan/penyerahan M-22 sesi lain.

## Perubahan skema, rollback dan tinjauan arsitek

Up/down/up 0066 diuji sebelum data bisnis Bahan dibuat. Down menolak jika ada
sesi Bahan agar arsip tidak terhapus; data produksi tidak boleh dibuang untuk
memaksa rollback. Sesudah data tersedia, hentikan pembuatan sesi Bahan dan
gunakan perbaikan maju, sementara sesi Aset tetap tersedia.

Tinjauan arsitek terhadap 0066/ledger dan integrasi bersama tetap diperlukan
sebelum merge. Penyelarasan enum M-22 sesi lain, CI remote, staging, dan kamera
Android/iOS pada perangkat fisik belum selesai pada audit ini.
