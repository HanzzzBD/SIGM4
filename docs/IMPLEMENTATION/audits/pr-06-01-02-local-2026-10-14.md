## Keputusan pengguna

Empat jawaban AskUserQuestion dicatat pada PRD M-16 dan diterapkan:

1. Hari inklusif WIB, bawaan 30 hari terakhir, maksimum 366 hari; pembanding
   tepat sebelumnya dengan jumlah hari sama. Rentang lebih panjang disiapkan
   untuk kontrak ekspor PR-06-08.
2. report.view bersama izin sumber, irisan scope di SQL, nilai perolehan tanpa
   asset.view_financial tidak dipilih, biaya memerlukan maintenance.view_cost.
   Scope yang belum memiliki aturan ditolak.
3. Delapan jenis FR-16.1, katalog terfilter izin, registry penyedia dan penjaga
   scope. Jenis tanpa perhitungan ditandai BELUM_TERSEDIA dan menjawab 503
   SERVICE_NOT_READY; tidak menghasilkan angka kosong semu.
4. Own berdasarkan subjek: penanggung jawab aset, pemohon reservasi, peminjam,
   pelapor kerusakan, teknisi WO, pengusul pengadaan/penghapusan, pemohon bahan.
   Join dimensi tetap memakai scope domain; report own bukan kepemilikan semua
   tabel yang dijoin. Pinjaman sendiri dapat memakai aset milik pihak lain jika
   izin asset.view mengizinkannya.

## Perubahan

- packages/schemas/analytics: query, delapan jenis, periode, filter efektif,
  kolom bertipe/sensitivitas, amplop report dan body ekspor XLSX/PDF.
- M-16 registry provider menolak jenis/registrasi ganda, menjaga metode class;
  dependency injection AppDeps memungkinkan PR perhitungan mendaftarkan provider
  tanpa registry route kedua. Default produksi belum mempunyai provider.
- GET /analytics dan GET /analytics/:jenis terdaftar pada OpenAPI/gerbang RBAC.
  report.view bukan pengganti hak sumber. R-07 dan SYSTEM ditolak; konteks pemohon
  diperlukan untuk ekspor, dengan report.export sebagai irisan tambahan.
- Predicate sumber memakai owner/assigned/restricted yang didefinisikan.
  M-22 menyediakan scope baca permintaan melalui permukaan publik, agar saldo
  global tidak memperluas akses terhadap permintaan orang lain. Tidak ada bypass
  Administrator atau scope all bawaan.
- Provider menerima periode kanonik terpisah dari query tanpa tanggal mentah;
  pembanding memakai scope yang sama. Metadata ringkasan utama/pembanding harus
  identik. Metadata sensitivitas wajib; kolom tak berizin ditolak sebelum query.
  DECIMAL string menjaga presisi, kolom ekstra/tipe yang menyimpang ditolak.
- Total grup, halaman, ringkasan dan pembanding disajikan satu statement SQL CTE,
  sehingga memakai snapshot yang sama. LIMIT/OFFSET parameter dan sort allow-list
  bertie-breaker key grup. Halaman kosong mempertahankan total scoped.
- Transaksi READ COMMITTED kernel dipertahankan, dengan SET TRANSACTION READ ONLY
  untuk laporan. Mutasi melalui fungsi provider ditolak PostgreSQL.
- Cache-Control private, no-store; tidak ada cache bersama lintas scope.
- Dokumentasi PRD M-16, SDD auth/API, status/log phase, indeks API dan snapshot
  health/OpenAPI diperbarui. Scope/fondasi ini tidak mengubah kalkulasi domain.
