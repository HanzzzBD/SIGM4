## Implementasi

POST /room-fixed-schedules/import menerima filename/content_base64 (maksimal
6.000.000 byte CSV). Header wajib, CSV, UTF-8 dan ukuran diperiksa sebelum job
dibuat. Template CSV E.5.3 memuat contoh dan tanggal tahun ajaran aktif; pengguna
mengganti kode ruangan. GET /room-fixed-schedules/import/{id} hanya pengunggah,
termasuk pemegang scope all. HTTP 200 untuk hasil selesai, 202 untuk job antrean.
Hash SHA-256 per pengunggah dengan advisory lock menjamin replay 24 jam.

Job, cursor, counter dan laporan mempunyai constraint. Setiap baris memakai
TransactionScope yang sama untuk BlockService, aturan, slot dan audit/progres.
Job row lock melindungi retry; room row lock melindungi pemeriksaan identik.
Galat bisnis/23P01 menjadi laporan baris, galat sistem rollback dan diulang.
Hari kerja/jam/granularitas/tahun aktif serta hari libur mengikuti BlockService.
Konflik diperiksa dalam horizon materialisasi yang sama dengan input manual;
job materialisasi berikutnya tetap menangani perpanjangan horizon.

Outbox RoomScheduleImportRequested → BullMQ room-schedule-import, ID tetap dan
RETRY_OPTIONS. Runner memeriksa ulang izin dan status AKTIF, lalu melanjutkan
cursor. Percobaan sistem terakhir menutup GAGAL. Berkas dibuang ketika terminal.
RoomScheduleImportCompleted → NT-56 wajib In-app/Push, dedupe per event, tautan
/kalender-ruangan?kelola=true&impor={id}. Penghitungan selesai dan event atomik.

API importReportView menutup rincian/nama tepat 30×24 jam setelah selesai/gagal.
Cleanup personal-data-retention memanggil pemilik M-07, batch 200/SKIP LOCKED,
penanda report_purged_at dan audit; status/hitungan/audit tetap. UI menampilkan
progres, laporan, unduh/koreksi CSV aman dari formula, retensi dan pemulihan URL.
Cache laporan dipisah akun; kalender dan daftar blokade disegarkan setelah selesai.

Parameter reservasi.durasi_maksimum_jam bertipe BILANGAN_BULAT, bawaan 12,
rentang 1–24 di metadata M-20/P-70. Layanan M-07 membaca setiap permintaan dan
memeriksa selisih waktu tanpa pembulatan per kemunculan. Preview menandai tanggal
TIDAK_SAH beserta batas jam, submit menolak 422 sebelum menulis reservasi/slot.
Jalur M-08 yang menangani gabungan ruangan/aset juga menerima batas ruangan,
sehingga normalisasi aset_pendukung tidak melewati validasi tersebut. Reservasi
aset tanpa ruangan tetap menggunakan durasi per role. Pengajuan lama tetap utuh.

Migration 0073 menambah parameter, tabel job, indeks replay/retensi/aturan aktif.
Down membuang job/indeks/parameter; jadwal dan slot hasil impor tetap tersimpan.
